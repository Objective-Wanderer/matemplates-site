Questions, answered

What is n8n, and do I need my own instance?

n8n is a free, open-source workflow automation tool (self-hosted, or their cloud plan). You'll need a working n8n instance to import these templates — self-hosted or n8n Cloud both work.

What exactly do I get after buying?

An import-ready workflow JSON file, a README with step-by-step setup (including where each API key goes), and support by email if anything doesn't work as described.

Are there running costs?

n8n itself is free self-hosted. The lead enrichment template uses Apify for scraping (free tier available) and optional lookup APIs — costs are usage-based and documented in the README so there are no surprises.

What if it doesn't work for me?

Every template has a test mode that runs on dummy data with zero API cost. If it doesn't do what the page says, email within 30 days for a full refund — no questions asked.
