FAQ

Questions, answered

What is n8n, and do I need my own instance?

n8n is a free, open-source workflow automation tool (self-hosted, or their cloud plan). You'll need a working n8n instance to import these templates — self-hosted or n8n Cloud both work.

What exactly do I get after buying?

An import-ready workflow JSON file, a README with step-by-step setup (including where each API key goes), and support if anything doesn't work as described.

How long does setup actually take?

About 15 minutes for the lead enrichment template, 5 for the notifier. Download, import the JSON, paste in the API keys the README points to, run the built-in test mode. No coding.

Does it work on n8n Cloud or only self-hosted?

Both. The templates use standard nodes available on every n8n plan. Self-hosted gives you no execution limits; n8n Cloud works too within its plan quotas.

Are there running costs?

n8n itself is free self-hosted. The lead enrichment template uses Apify for scraping (free tier available) and optional lookup APIs — costs are usage-based and documented in the README so there are no surprises.

Can I modify the workflows?

Yes — it's your copy. Add nodes, change triggers, rebrand the outputs. The only thing you can't do is resell or redistribute the template files themselves.

Do I get future updates?

Yes. Every improvement to a template you own is a free re-download from your Gumroad library, forever.

What if it doesn't work for me?

Every template has a test mode that runs on dummy data with zero API cost. If it doesn't do what the page says, email within 30 days for a full refund — no questions asked.

Can I use this for client work?

Absolutely — agencies and freelancers deploy these for clients all the time. One license per deployment; need many client installs? Email for a bulk arrangement.
