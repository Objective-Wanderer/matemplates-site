n8n + WhatsApp + Supabase: Build an Automated Lead Capture & Qualification Pipeline

Published October 20, 2026 • 8 min read

Capturing leads from WhatsApp manually is a bottleneck. When prospective clients message your business outside of operating hours, delays in response directly lower your conversion rate. By combining n8n, the WhatsApp Business Cloud API, and Supabase, you can instantly ingest messages, qualify leads through automated prompts, and persist structured customer profiles in real time.

The Architecture of the Pipeline

A reliable WhatsApp automation workflow requires three core moving parts working in sync:

  • WhatsApp Cloud API Webhook: Receives inbound messages and payloads directly from Meta's servers when a user writes to your business number.
  • n8n Core Workflow Engine: Parses incoming webhooks, extracts sender details, runs qualification logic or AI scoring, and orchestrates database storage.
  • Supabase PostgreSQL Database: Stores lead profiles, conversation states, and qualification metadata with Row Level Security (RLS) enabled.

Why Supabase over Google Sheets for WhatsApp CRM?

While Google Sheets is great for rapid prototyping, high-volume WhatsApp messaging creates race conditions, rate limits (60 requests/minute), and row locking issues. Supabase provides instantaneous SQL indexing, relational data structures for message logs, and native Row Level Security so multi-agent or multi-tenant setups remain secure.

Step 1: Setting up the WhatsApp Webhook in n8n

Create a new n8n workflow and add a Webhook trigger node. Set the HTTP method to GET for webhook verification (Meta sends a challenge token) and POST for incoming message payloads.

// Sample n8n Webhook JavaScript extraction node
const body = $input.item.json.body;
const entry = body.entry?.[0];
const change = entry?.changes?.[0];
const message = change?.value?.messages?.[0];
const contact = change?.value?.contacts?.[0];

return {
  phone: message?.from,
  name: contact?.profile?.name,
  text: message?.text?.body,
  timestamp: message?.timestamp
};

Step 2: Automating Lead Qualification

Once the webhook normalizes the incoming message, route the payload through a conditional switch or an LLM node to determine intent:

  • Hot Lead: Asking about pricing, booking, or immediate purchase. Trigger an instant WhatsApp template response and notify your sales team via Telegram or Slack.
  • Support Inquiry: Asking for documentation or troubleshooting. Auto-reply with knowledge base links.
  • Spam / Unqualified: Log to database without immediate interruption.

Step 3: Storing Leads in Supabase

Use the n8n Supabase node (or standard HTTP Request node pointing to your Supabase REST API) to upsert the lead record:

// Supabase upsert payload structure
{
  "phone_number": "+1234567890",
  "full_name": "John Doe",
  "last_message": "Interested in your n8n templates bundle",
  "status": "qualified",
  "updated_at": "2026-10-20T12:00:00Z"
}
